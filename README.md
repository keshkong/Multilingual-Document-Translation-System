# Multilingual Document Translation System

A Python-based project focused on multilingual text and document translation.

## Overview
This project explores multilingual translation using Python, natural language processing, and translation APIs.

## Technologies
- Python
- PyQt5
- Natural Language Processing (NLP)
- LibreTranslate API
- sacremoses
- python-docx

## Features
- Multilingual text translation
- Language selection
- Document processing
- Translation integration

## Project Structure
The source code, documentation, and supporting resources will be organized into separate folders.
